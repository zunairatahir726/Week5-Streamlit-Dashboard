# Amazon Reviews Sentiment Analysis Dashboard

## Project Overview
This project performs sentiment analysis on Amazon Alexa customer reviews using Machine Learning and Natural Language Processing (NLP).

## Features
- Home Page
- Data Overview
- Feedback Distribution
- Positive Reviews Word Cloud
- Negative Reviews Word Cloud
- Sentiment Prediction
- Confidence Score

## Dataset
Amazon Alexa Reviews Dataset

## Machine Learning Models
- Multinomial Naive Bayes
- Logistic Regression

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- WordCloud
- Joblib

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
